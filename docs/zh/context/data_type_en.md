# Data Types

<!-- md-trans-meta sourceCommit=unknown translatedAt=2026-09-23T13:20:06.545Z -->

For the complete list of data types supported when creating an aclTensor through the **aclCreateTensor** API, see "Data Types and Related APIs > aclDataType" in [*Runtime API*](https://hiascend.com/en/document/redirect/CannCommunityRuntimeApi).
In the Parameters section of a two-phase API, the supported data types are represented by the following abbreviations for ease of description.

|     ACL_INT16     |          INT16           |
|    ACL_UINT16     |          UINT16          |
|    ACL_UINT32     |          UINT32          |

|    ACL_UINT64     |          UINT64          |
